What's real

The connectome, the leaky integrate-and-fire dynamics, all 165,122 traced neurons and their 10,228,000 measured, signed synapses, the six motor populations (real annotated subclasses fl / ml / hl / wm / hm / nm), and the learning rule — dopamine-gated depression at the Kenyon-cell → MBON synapse, the one place this repo lets a weight move — are unmodified from the real simulation code driving the rest of this project.

What's chosen

Nothing in a real fly asks it to drum. A tonic drive onto the ventral-nerve-cord's own walking pattern-generator population is what wakes the circuit up at all, and the reward — how closely six leg/wing/haltere/neck motor readouts match six real human grooves — is invented, exactly like the "novelty" reward disclosed elsewhere in this repo. The timestep was also widened, 0.2ms → 2.0ms, to make a bar simulate in about a minute instead of about eight.

Live vs. recorded

On CPU, one simulated bar takes about a minute — 500× slower than the audio it produces. On a real GPU (via flysim_gpu.py, sparse synaptic input as one CSR matrix–vector product per step), the same bar simulates in real time. Run fly_drums_live_server.py and this page finds it and streams each bar over a WebSocket the moment it's computed — training and performance both genuinely live. With no server reachable — which is the only option once this page is off your machine, since a published copy of it can't reach into your GPU — it falls back to fly_drums_sim.py's recorded output instead, same page, same visuals.
